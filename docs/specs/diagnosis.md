# 診断仕様

回答から診断結果（キャラクター）を作るときの規則。ゲームバランスの調整に合わせて更新する。この仕様を支える設計判断（乱数を使わない、Zod スキーマを唯一の定義にする など）は [ADR 0006](../decisions/0006-diagnosis-spec-and-schema.md) を参照。

## 質問

- 質問は 10 問。各質問に 3〜4 個の選択肢がある。
- 選択肢ごとに、能力値へ加算・減算する点数（整数）を持つ。

## 能力値

- 6 種類: 力（strength）・知力（intelligence）・体力（vitality）・素早さ（agility）・器用さ（dexterity）・運（luck）。
- 値は 1〜100 の整数。
- 回答から能力値を作る手順:
  1. 選んだ選択肢の点数を、能力値ごとに合計する。
  2. 質問データから「取りうる最小値〜最大値」を求め、合計を 1〜100 に線形に変換して整数に丸める。
  3. 最小値と最大値が等しい（どの選択肢でも変化しない）能力値は、中央の 51 とする。

## 職業

- 職業ごとに能力値の重み（正の整数）を持つ。
- 能力値と重みの積の合計が最も大きい職業を選ぶ。同点ならデータの並び順で先の職業を選ぶ。
- 重みの合計が大きい職業ほど選ばれやすくなるため、重みの合計は全職業でそろえる。
- どの職業も、何らかの回答で選ばれうるようにする。

## スキル

- 各スキルは、対応する能力値を 1 つ持つ。
- 選ばれた職業のスキル候補から、対応する能力値が高い順に 3 つ選ぶ。同点なら職業のスキル候補の並び順で先のスキルを選ぶ。

## ID の形式

- データ間をつなぐ ID は、英小文字で始まるケバブケース（例: `power-strike`、`q1`）とする。
- 選択肢の ID は、同じ質問の中でだけ一意であればよい。
