# 0002: ドキュメントの言語と JSDoc の方針

- ステータス: 採用
- 日付: 2026-10-13

## 背景

実装と保守は主に AI コーディングエージェントが行い、人間は README や設計文書で全体を把握する。読み手ごとに言語を決めておかないと、日本語と英語が混在し、エージェントが従う規約もぶれる。また、エージェントが関数やコンポーネントの役割を誤解しないよう、コード上の説明を必須にしたい。

## 決定

### 言語

| 読み手          | 言語   | 対象                                                                                     |
| --------------- | ------ | ---------------------------------------------------------------------------------------- |
| AI エージェント | 英語   | `AGENTS.md`、`.cursor/rules/*.mdc`、JSDoc、コードコメント、テスト名、ESLint のメッセージ |
| 人間            | 日本語 | `README.md`、`docs/**`（ADR を含む）、画面の文言、`.env.example` のコメント              |

識別子（変数名・関数名・ファイル名）は常に英語とする。

### JSDoc

- export するすべての関数・コンポーネント・hook・定数・型・スキーマに、英語で正確な JSDoc を書く。
- 1 行目に「何をするか／何を表すか」を 1 文で書く。引数ごとに `@param`、戻り値があれば `@returns`、例外を投げうるなら `@throws` を書く。型は TypeScript に任せ、JSDoc では繰り返さない。
- コンポーネントの props は props 型の各プロパティに JSDoc を書く。
- 挙動を変えたら JSDoc も更新する。

## 検討した代替案

- `eslint-plugin-jsdoc` による JSDoc の必須化: 書き漏れを機械的に検出できるが、2026-10 時点の最新版（65.x、および 64.3.5 以降）は Node.js `>=24.15.0` を要求し、現在のローカル環境（24.13.1）を満たさない。当面はルールと `AGENTS.md` で規約を示し、Node.js を更新した時点で導入を再検討する。

## 影響

- テスト名を日本語から英語に変更した。
- 画面の文言は日本語のままとする。
